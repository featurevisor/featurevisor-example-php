# featurevisor-example-php

Example PHP application using Featurevisor PHP SDK: https://github.com/featurevisor/featurevisor-php

Learn more about Featurevisor: https://featurevisor.com

## Installation

Clone the repository, and run this with Composer:

```
$ composer install
```

## Usage

```
$ php src/index.php
```

## Featurevisor project

Uses this Featurevisor project to fetch the configuration from: https://github.com/featurevisor/featurevisor-example-cloudflare
